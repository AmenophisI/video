1 概要

本書は、端末内の動画ファイルを動画専用ライブラリとして一覧・検索・整理・再生する Android アプリの画面仕様を定義する。各画面の画面イメージは検討中の One UI ダークモードのデザイン を HTML/CSS で再現したもので、表示項目・操作・遷移・状態などの仕様は アプリの実挙動 に基づく。

対象プラットフォームAndroid スマートフォン／タブレット
動画の検出端末内に保存された動画を自動的に検出し、動画専用のライブラリとして表示する（ユーザーによる手動登録は不要）。
テーマ / アクセントOne UI ダークモード（黒基調）。アクセントは Samsung ブルー #4D90FE（選択状態・進捗・主要ボタンに限定使用）。モード切替は持たずダーク固定。
ナビゲーションボトムナビゲーション4タブ（動画／フォルダ／リスト／設定）＋ プッシュ遷移（詳細・プレイヤー・フォルダ内・プレイリスト内）
プライバシー動画の情報は端末内でのみ扱う。共有を実行したときだけ、選択した外部アプリへ一時的にアクセスを許可する。

凡例

タブ画面（ボトムナビ） プッシュ画面（戻る） ボトムシート ダイアログ 緑 成功トースト文言

4 共通仕様

4.1 デザインシステム（One UI ダークモード）

One UI のダークモードを基調に、Samsungブルーをアクセントとしたスタイル（ダーク固定・モード切替なし）。色はトークン化し全画面で統一。

トークン用途値
bg / surface画面・面の背景（黒基調）#000000
surfaceContainer検索バー・カード・チップ背景#1C1D20
onSurface主要テキスト#F4F5F6
onSurfaceVariant副次テキスト・アイコン#A9ADB3
accent選択状態・進捗・主要ボタン#4D90FE
accentContainerアクセントの暗色背景#16324F
divider区切り線#2A2B2E
タイポグラフィNoto Sans JP。大見出し 23px Bold、本文 14px、副次 11.5〜12.5px。
角丸検索バー 22px（ピル）、カード／グループ 18px、サムネ 14〜16px、端末フレーム 30px。
アクセント方針ブルーは「選択中タブ」「視聴進捗バー」「主要ボタン（再生）」「トグルON」「スライダー」に限定。情報は白／グレーで表現し、黒基調にコントラストを確保。

4.2 共通コンポーネント

コンポーネント説明使用画面
ステータスバー時刻＋電波／Wi-Fi／電池（端末標準の模式表現）。全画面

ピル検索バー角丸22pxのフィルド検索入力。プレースホルダで対象を明示。動画／フォルダ／フォルダ内動画
並び替え行左に「○○順 ▾」テキストボタン、右に表示切替（グリッド／リスト）と選択アイコン。動画／フォルダ／フォルダ内動画
ボトムナビ動画／フォルダ／リスト／設定の4タブ。選択中はアクセント色。タップに加え、画面を左右にスワイプしても隣のタブへ切り替えられる（動画 ⇔ フォルダ ⇔ リスト ⇔ 設定）。最後に開いていたタブを記憶し、次回アプリ起動時は前回のタブで開く。タブ画面

4.3 共通状態

各画面は、データの読み込み状況と権限の状態に応じて表示が切り替わる。

状態表示主な文言
ローディング中央にプログレスインジケータ—
エラー中央にエラーメッセージ例外内容を表示
空状態中央に説明テキスト「動画が見つかりません」「フォルダが見つかりません」「プレイリストがありません」「このフォルダに動画はありません」「動画がありません」
権限：許可(granted)全動画を表示「すべての動画にアクセス可能」
権限：限定(limited)選択動画のみ表示＋上部に追加アクセス導線バナー「選択した動画のみアクセス可能」／「選択した動画のみ表示しています。必要な動画が見つからない場合はアクセス対象を追加してください。」
権限：拒否(denied)権限要求パネル（許可ボタン＋設定導線）「動画へのアクセス許可が必要です」「端末内の動画を一覧表示するため、メディアアクセス権限を許可してください。」
権限：不明(unknown)確認中表示「不明」

概要・到達経路

8 入力規則・バリデーション

対象規則エラー文言
ファイル名使えない文字（\ / : * ? " < > |）は不可。空欄不可。拡張子は元のものが維持される。「ファイル名を入力してください」／「ファイル名に \ / : * ? " < > | は使えません」／「このファイル名は使えません」
フォルダ名 / パス使えない文字（\ : * ? " < > |）は不可（「/」は階層の区切りとして使用可）。空欄不可。「フォルダを入力してください」／「フォルダ名に \ : * ? " < > | は使えません」／「このフォルダ名は使えません」
同名の重複同じフォルダ内に同名の動画があると検知。コピー時は自動的に別名（例:「名前 (copy)」「名前 (2)」…）を付ける。「同じフォルダに同名の動画があります」／「移動先に同名の動画が○件あります」
競合時の選択移動／コピー先に同名がある場合の選択。スキップ＝処理しない／別名保存＝別名で保存（コピー時のみ）／置き換え＝既存を上書き。—
